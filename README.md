Assignment Submission and Deadline Reminder

Project Overview

This project uses n8n to automate assignment submission and deadline reminders for students through email.

Technologies Used

- n8n Workflow Automation
- Google Sheets
- Gmail
- Schedule Trigger
- IF Node

Workflow Modules

1. Schedule Trigger: Starts the workflow automatically according to the configured schedule.
2. Google Sheets: Retrieves assignment information from the spreadsheet.
3. IF Node: Checks the configured conditions for sending reminders.
4. Gmail: Sends email reminders when the conditions are met.

Features

- Automated assignment reminders
- Deadline monitoring
- Google Sheets integration
- Email notifications
- Reduced manual work

Setup Instructions

1. Download the workflow JSON file from this repository.
2. Open n8n and import the JSON workflow.
3. Configure your Google Sheets and Gmail credentials.
4. Update the spreadsheet details and conditions.
5. Test the workflow before activating it.

Project Purpose

To help students remember assignment deadlines and improve timely submissions through automation.
